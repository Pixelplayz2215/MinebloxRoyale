Downloaded by your launcher (not included): Minecraft 26.3 (Mojang), Fabric Loader 0.19.5 and Intermediary 26.3
(FabricMC, Apache-2.0), and a Java 25 runtime if you don't have one. The Modrinth-format (.mrpack) downloads fetch
Fabric API and e4mc from Modrinth instead of carrying them.

Room codes are looked up through ntfy.sh, a free public message service; each room's address is stored there
scrambled with its code, so only someone who has the code can read it.

Country flags: when the game starts it asks Cloudflare (https://www.cloudflare.com/cdn-cgi/trace) which country your
internet connection is in. Only the two-letter country is kept and shown to the other players in your room, never your
address. Type /flag off in the game to hide yours.

Mineblox Royale itself: MIT licence. Not affiliated with Mojang, Microsoft, Roblox Corporation or Epic Games.
Roblox and Fortnite content is read from the player's own installed copies and is never included or copied.

Java runtime (only in the "Prism Launcher, ready to play" package: Prism Launcher/java/java-runtime-epsilon): Mojang's Java 25
runtime for Minecraft, the Microsoft Build of OpenJDK 25.0.1, GPL v2 with the Classpath Exception. Its own notices are in its legal
folder. It ships so the game starts without Prism Launcher having to download Java first.
