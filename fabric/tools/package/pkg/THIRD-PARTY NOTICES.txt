Mineblox Royale v1.0.1.1 includes these programs, each under its own licence (not every download has all of them:
Prism Launcher and the Visual C++ runtime are only in the Prism "ready to play" download, and Melty's download
has only the mods and the minebloxroyale folder: Melty brings Prism Launcher, Java and Fabric Loader itself):

Prism Launcher 11.1.1 (portable)
  Licence: GPL-3.0. Source code: https://github.com/PrismLauncher/PrismLauncher (tag 11.1.1)

Microsoft Visual C++ runtime 14.51  (vcruntime140*.dll, msvcp140*.dll beside prismlauncher.exe)
  Microsoft's redistributable files, which Prism Launcher needs to start on PCs that don't have them installed.

Fabric API 0.161.0+26.3  (in the mods folder)
  Licence: Apache-2.0. https://github.com/FabricMC/fabric

e4mc 6.2.2  (in the mods folder)
  Licence: MIT. https://modrinth.com/mod/e4mc  (a free relay so friends can join your world without port forwarding)

e4mc's relay libraries  (minebloxroyale\e4mc: netty_quiche_windows_x86_64_74.dll, iroh_java_windows_x86_64_57caf9a.dll)
  e4mc's own builds, as it downloads them from https://natives.e4mc.link (byte for byte the same; they ship so the
  game needn't download them). netty-incubator-codec-quic (Apache-2.0, https://github.com/netty/netty-incubator-codec-quic)
  with Cloudflare's quiche (BSD-2-Clause) and Google's BoringSSL (OpenSSL/ISC licences); iroh by n0 (MIT or Apache-2.0,
  https://github.com/n0-computer/iroh) in e4mc's binding (MIT, https://github.com/vgskye/e4mc-minecraft-architectury).

FFmpeg 9.0, LGPL shared build  (minebloxroyale\ffmpeg)
  Licence: LGPL-2.1 or later (see LICENSE.txt in that folder). Source: https://ffmpeg.org
  Used only to decode Roblox sounds from your own Roblox install.

Downloaded by your launcher (not included): Minecraft 26.3 (Mojang), Fabric Loader 0.19.5 and Intermediary 26.3
(FabricMC, Apache-2.0), and a Java 25 runtime if you don't have one. The Modrinth-format (.mrpack) downloads fetch
Fabric API and e4mc from Modrinth instead of carrying them.

Room codes are looked up through ntfy.sh, a free public message service; each room's address is stored there
scrambled with its code, so only someone who has the code can read it.

Mineblox Royale itself: MIT licence. Not affiliated with Mojang, Microsoft, Roblox Corporation or Epic Games.
Roblox and Fortnite content is read from the player's own installed copies and is never included or copied.

Java runtime (only in the "Prism Launcher, ready to play" package: Prism Launcher/java/java-runtime-epsilon): Mojang's Java 25
runtime for Minecraft, the Microsoft Build of OpenJDK 25.0.1, GPL v2 with the Classpath Exception. Its own notices are in its legal
folder. It ships so the game starts without Prism Launcher having to download Java first.
